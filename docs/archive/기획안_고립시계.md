# 고립 시계 기획안

2026 빅콘테스트 AI데이터 활용 분야(주제2) 참가안입니다. 사회적 고립을 "위험하다/아니다"가 아니라 **진행 단계**로 보고, 다음 단계로 넘어가기 전에 개입하는 에이전트를 제안합니다.

문서 버전: [고립 시계 기획안 (공유 문서)](https://claude.ai/code/artifact/73b2598e-0310-46bf-b8a2-9d0985a807ad)
이전 방향(5060 타겟)은 `docs/기획안_5060.md`에 남겨 두었습니다.

## 1. 무엇을 만드는가

**지역·인구집단이 고립의 몇 단계에 와 있는지 판정하고, 다음 단계로 넘어가기 전에 개입하는 에이전트.**

기존 복지는 "위험한가"를 묻습니다. 이 에이전트는 "지금 몇 시인가"를 묻습니다. 3단계에서 발견하면 돌봄이지만 1단계에서 발견하면 예방입니다.

### 과제 필수 요소와의 대응

주제설명자료에서 `(예시)`로 표기된 것은 따를 의무가 없습니다. 고립 위험도 5단계 실시간 지수화와 운영 흐름이 여기 해당합니다. 필수는 아래 네 가지입니다.

| 필수 요소 | 이 기획의 답 |
|---|---|
| 고립 위험 신호·특성·영향 요인 도출 | 단계별로 다른 지표 세 개를 제공 데이터에서 도출하고 순서를 실증 |
| 위험 수준에 따른 복지자원·대응 추천 | 단계마다 처방이 다름. 1단계 일자리, 2단계 모임, 3단계 돌봄 |
| 예측·분류 모델과 성능 평가 | 단계 분류 + 전이 예측이 에이전트의 핵심 엔진 |
| 지역 및 인구집단 단위 | 판정 단위가 행정동 × 성 × 연령대. 개인을 특정하지 않음 |

## 2. 4단계 모델

| 단계 | 상태 | 판정 지표 |
|---|---|---|
| 0 안정 | 근로 리듬 유지 | 평일/주말 결제비가 낮음 |
| 1 역할 상실 | 은퇴 이행 시작, 관계는 유지 | 평일/주말비 ↑, 사회적 소비 유지 |
| 2 관계 축소 | 사람 만나는 소비가 끊김 | 사회적 소비 비중 급락 |
| 3 생존 소비 | 필수 소비만 남음 | 필수 업종 쏠림 ↑, 이용 업종 수 ↓ |

### 단계 가설 검증 (제공 데이터, 춘천 남성 주민 결제)

| 지표 | 30대 | 40대 | 50대 | 60대 | 70대 | 80대 |
|---|---|---|---|---|---|---|
| 평일/주말 결제비 | 0.83 | 0.84 | **0.95** | 1.10 | 1.25 | 1.40 |
| 사회적 소비 % | 33.8 | 32.3 | 32.9 | **28.8** | 22.8 | 22.9 |
| 필수 소비 % | 51.6 | 52.1 | 50.4 | 50.2 | 52.9 | **60.9** |
| 이용 업종 수 | 82 | 82 | 84 | 83 | 80 | **74** |

세 지표가 **연령 순서대로, 겹치지 않고** 움직입니다. 50대에서 평일화가 먼저 오고(1단계), 60대에서 사회적 소비가 꺾이며(2단계), 80대에서 필수 소비가 치솟고 업종이 줄어듭니다(3단계). 동시에 움직였다면 단계로 나눌 수 없었을 것이므로, 이 순차성이 모델의 근거입니다.

## 3. 에이전트 설계

사용자는 동 주민센터 복지 담당자와 복지관·중장년센터 담당자입니다.

### 매달 돌아가는 루프

1. 지표 갱신 — 동 × 성 × 연령대의 소비·활동 지표 재계산
2. 공통 충격 보정 — 명절·한파처럼 전체가 떨어진 효과 제거
3. 단계 재판정
4. 전이 예측 — 다음 단계로 넘어갈 확률이 높은 집단 추출
5. 원인 분해 — 어느 지표가 단계를 끌어올렸는지 설명
6. 자원 매칭 — 단계에 맞는 복지서비스·봉사·기관 연결
7. 실행안 발행 — 담당 부서, 대상 규모, 근거, 확인 지표
8. 피드백 반영 — 담당자가 반려하면 임계값 조정

1~4는 모델과 규칙이, 5~7은 LLM이, 8은 사람이 합니다.

### 도구

| 도구 | 입력 → 출력 |
|---|---|
| `stage_now` | 동·성·연령 → 현재 단계와 지표 값 |
| `stage_risk` | 동·성·연령 → 다음 단계 진입 확률 |
| `shock_filter` | 기간 → 공통 변동 제거한 지표 |
| `explain_stage` | 집단 → 단계 판정 기여 요인 |
| `match_resource` | 단계 + 지역 → 복지자원 목록 |
| `find_places` | 좌표 + 반경 → 인근 시설과 거리 |
| `make_plan` | 위 결과 → 실행안과 판단 로그 |

### 단계별 처방

| 단계 | 개입 목표 | 연결할 자원 (확보 완료) |
|---|---|---|
| 1 역할 상실 | 역할 되찾기 | 중장년 경력지원제, 재취업지원서비스, 중장년내일센터 |
| 2 관계 축소 | 만날 자리 만들기 | 1365 봉사 일감 216건, 복지관 프로그램, 평생교육 |
| 3 생존 소비 | 돌봄 연결 | 노인맞춤돌봄, 경로식당, 방문 안부 |

## 4. 모델링

| 모델 | 내용 |
|---|---|
| 단계 분류기 | 분위수 기반 임계값으로 단계를 정의하고 머신러닝으로 재현. SHAP로 판정 기여 요인 분해 |
| 전이 예측기 | 다음 단계 진입 확률. 6개월 데이터의 한계를 유사 시계열 가정과 합성 데이터로 보완 |
| 공통 충격 보정 | 명절·한파 등 전체 변동을 분리. 잔차만 신호로 사용 |

### 성능 평가

| 무엇을 | 어떻게 |
|---|---|
| 단계 분류 일관성 | 교차검증 정확도와 혼동행렬, 임계값 민감도 |
| 보정 효과 | **헛경보 감소율** — 추석·한파 구간의 오탐지가 얼마나 줄었는지 |
| 단계의 현실 적합성 | 1인세대율, 우울감 경험률, 고독사 통계와 방향 일치 여부 |

헛경보 감소율이 가장 중요합니다. 현장에서 경보를 믿을지를 결정하는 수치이고, 다른 팀이 제시하기 어려운 지표입니다.

## 5. 데이터 계획

### 1층 — 제공 데이터 (단계 판정의 근거)

단계 판정 지표 세 개가 전부 제공 데이터에서 나옵니다. 기업 데이터 대회라는 취지에 맞추는 지점입니다.

### 2층 — 무료 공공데이터

확보 완료 7종: 행안부 1인세대수·인구수, 상가(상권)정보, SGIS 행정동 경계, 복지로 중앙부처·지자체 복지서비스, 1365 봉사참여정보, 고독사 실태조사.

추가 예정: 기상청 ASOS(한파·폭염 보정), 고용보험 자격상실자(1단계 검증), 지역사회건강조사 우울감(외부 검증), 시설 표준데이터 4종(3단계 자원).

### 3층 — 페르소나 합성 데이터

제공 데이터는 집계값이라 한 사람이 단계를 옮겨가는 과정을 볼 수 없습니다. 이 공백만 합성으로 메웁니다.

- **생성 방식**: 집계 지표에서 단계별 표준 궤적을 추정 → 페르소나 12명 × 24개월 궤적 생성 → 생성 규칙과 난수 시드를 문서화 (규정상 설명자료 제출 필수)
- **쓰는 곳**: 전이 예측 모델 학습·검증, 데모에서 한 사람의 단계 이동 장면
- **쓰지 않는 곳**: 단계 판정, 보고서의 핵심 수치

이 경계를 지켜야 "결국 가상 데이터 아니냐"는 질문에 답할 수 있습니다.

## 7. 활용 시나리오

춘천시 복지정책과 담당자가 한 달 동안 쓰는 모습입니다. 수치는 실제 산출값이고, 이 흐름이 그대로 발표 데모 대본이 됩니다.

### 1. 월간 브리핑

| 순위 | 대상 | 등급 | 유형 |
|---|---|---|---|
| 1 | 효자2동 · 60대 남성 | 1단계 → **2단계** | 단계 상승 |
| 2 | 석사동 · 60대 여성 | 1단계 → **2단계** | 단계 상승 |
| 3 | 신북읍 · 70대 남성 | 2단계 유지 | 전이 확률 높음 |

브리핑 말미에 이렇게 적힙니다. "지난달 추석 주간은 전체 결제가 평소의 0.36배였습니다. 공통 변동으로 보정해 경보에서 제외했습니다."

보정이 없었다면 그 주 전체가 경보로 떴고, 담당자는 다음 달부터 이 시스템을 안 보게 됩니다.

### 2. 근거 확인

효자2동 60대 남성의 판정 근거입니다.

- 사회적 소비 비중이 32.9% → 28.8%로 하락 (30·40대 대비 −4.1%p)
- 평일/주말 결제비는 1.10으로 1단계 신호 유지
- 필수 소비는 50.2%로 아직 3단계 아님
- 이 동의 5060 남성 1인세대율은 45.0%로 춘천 상위권

판정: 일은 이미 놓았고, 이제 사람을 덜 만나기 시작했습니다. 아직 생활은 유지됩니다.

### 3. 단계에 맞는 처방

2단계이므로 돌봄이 아니라 **만날 자리**를 보냅니다.

- 중앙시니어통합복지센터 어르신 활동보조 봉사 (오전/오후 선택)
- 춘천동부노인복지관 관내 봉사자 모집
- 약사천 목공체험 프로그램 보조

같은 동의 **70대 여성은 3단계**라 처방이 다릅니다. 필수 소비 63.6%, 이용 업종 83종으로 생활이 좁아들어 노인맞춤돌봄과 경로식당이 나갑니다. 두 집단이 같은 동에 살아도 보내는 것이 다릅니다.

### 4. 수시 질의와 효과 확인

"우리 시에서 2단계가 가장 많은 곳은?"처럼 물으면 동 순위와 근거를 함께 답합니다. 다음 달 브리핑에는 지난달 처방의 결과가 붙고, 판단이 틀렸다면 임계값을 조정합니다.

### 발표 데모 구성 (3분)

| 시간 | 보여줄 것 |
|---|---|
| 0:00~0:30 | 지도 화면 — 47개 동이 단계별로 칠해진 모습 |
| 0:30~1:10 | 효자2동 60대 남성을 열어 2단계 판정 근거 확인 |
| 1:10~1:50 | 같은 동 70대 여성으로 전환 — 3단계, 다른 처방 |
| 1:50~2:30 | 추석 주간을 넣고 보정을 끄면 전체가 경보로 덮이는 장면 |
| 2:30~3:00 | 합성 페르소나 한 명의 24개월 궤적이 1→2→3단계로 넘어가는 타임라인 |

핵심은 네 번째 장면입니다. 보정을 끄자 화면이 경보로 덮이는 모습은 "왜 이 에이전트가 필요한가"를 설명 없이 보여줍니다.
