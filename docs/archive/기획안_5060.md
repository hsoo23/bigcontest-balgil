# 5060 타겟 계획안 (지표 재설계)

팀원이 작성한 「마실 일감」 기획안(5060 남성 대상 동네 일감·취미 연결)의 취지를 유지하되, 제공 데이터로 실제 산출 가능한 지표로 바꾼 안입니다. 아래 수치는 모두 배포 데이터를 직접 집계해 확인한 값이며, 재현 코드는 `scripts/explore_signals.py`입니다.

## 1. 타겟 정의

**50~60대, 특히 1인 가구 남성.** 2024년 고독사 사망자 3,924명 중 60대 남성 27.8%(1,089명), 50대 남성 26.2%(1,028명)로 5060 남성이 절반을 넘고, 남성이 여성의 약 5배입니다([보건복지부, 2024년 고독사 발생 실태조사](https://www.mohw.go.kr/board.es?mid=a10503010100&bid=0027&act=view&list_no=1488039)).

고령층(65세 이상)은 기존 복지 체계의 주 대상이자 공모전에서도 가장 흔한 타겟입니다. 반면 5060은 사망자 수가 가장 많음에도 노인복지 대상도, 청년 정책 대상도 아닌 사각지대에 있습니다. 이 점이 차별화 지점입니다.

## 2. 검증 결과: 무엇이 되고 무엇이 안 되는가

### 성립하지 않는 주장 (원 기획안 지표 ①)

"5060의 사회적 소비가 하반기에 하락한다"는 서사는 데이터로 뒷받침되지 않습니다. 주민 결제만 필터링한 사회적 소비 건수 비중의 7월 대비 12월 변화는 다음과 같습니다.

| 7월→12월 변화(%p) | 춘천 남 | 춘천 여 | 강남 남 | 강남 여 |
|---|---|---|---|---|
| 50대 | +0.3 | −0.7 | −1.0 | −1.4 |
| 60대 | +0.7 | +0.5 | −0.2 | +0.2 |
| 30대(대조군) | −1.2 | −1.8 | −1.1 | −1.5 |
| 40대(대조군) | −1.0 | −1.8 | −0.7 | −1.6 |

5060은 거의 변하지 않았고 30·40대가 오히려 더 하락했습니다. 6개월은 추세를 말하기에 짧고, 이 변화는 계절 효과로 보입니다.

### 부분적으로만 성립하는 주장: 하락은 60대부터

절대 수준을 같은 조건(주민 결제, 6개월 전체)으로 비교하면 다음과 같습니다.

| 사회적 소비 비중(%) | 30대 | 40대 | 50대 | 60대 | 70대 |
|---|---|---|---|---|---|
| 춘천 남 | 33.8 | 32.3 | 32.9 | **28.8** | 22.8 |
| 춘천 여 | 35.9 | 34.4 | 32.9 | **26.4** | 23.0 |
| 강남 남 | 30.4 | 27.5 | 28.9 | **26.0** | 24.4 |
| 강남 여 | 33.6 | 30.8 | 28.2 | **21.6** | 20.7 |

**50대는 30·40대와 사실상 차이가 없고, 뚜렷한 하락은 60대부터 시작됩니다.** 따라서 "5060은 사람 만나는 소비가 적다"는 단일 서사는 쓸 수 없습니다. 논지를 다음과 같이 나눕니다.

- **60대**: 사회적 소비 비중이 구조적으로 낮습니다. 특히 강남 여성은 30대 33.6%에서 21.6%로 12%p 낮습니다. 이 구간은 소비 지표로 직접 논증합니다.
- **50대**: 소비만 보면 문제가 드러나지 않습니다. 고독사 통계에서 가장 위험한 집단임에도 소비 행태로는 포착되지 않는다는 점 자체가 논지가 됩니다. **"기존 지표로는 보이지 않는 사각지대"**로 규정하고, 1인세대 밀도(지표 ②)와 일감 수요(지표 ④)로 접근합니다.

즉 전체 서사는 "줄어들고 있다"가 아니라 **"소비로 드러나는 60대의 고립과, 소비로는 드러나지 않는 50대의 고립은 다르게 잡아야 한다"**가 됩니다. 이 대비 자체가 분석의 발견이 됩니다.

### 관측 불가능한 것 (원 기획안 지표 ②)

"평일 낮 5060 체류"는 직접 관측할 수 없습니다. SK 시간대·요일 데이터에는 연령 구분이 없고, 성연령 데이터에는 시간 정보가 없습니다. 격자 단위 곱으로 근사할 수는 있으나, 낮에 움직이는 사람이 5060이라는 보장이 없어(생태학적 오류) 심사에서 공격받기 쉽습니다. 아래 지표 ②로 대체합니다.

## 3. 지표 설계

| 지표 | 정의 | 데이터 | 상태 |
|---|---|---|---|
| ① 사회적 소비 결핍도 | 같은 지역·같은 월에서 30·40대 대비 5060의 사회적 소비 비중 격차 | 카드 데이터2(주민 결제만) | 산출 확인 완료. 60대에서 유효하고 50대는 격차가 거의 없음 |
| ② 5060 1인세대 밀도 | 행정동별 50·60대 남성 1인세대 수와 비율 | [행안부 행정동 성별·연령별 1인세대수](https://www.data.go.kr/data/15097973/fileData.do) | **확보 완료.** 강남 22개 동, 춘천 25개 읍면동, 1세 단위 성별 집계 |
| ③ 또래 활동 기회 | 격자별 50대 비중과 평일·주말 활동 패턴 | SK 성연령 + 요일 | 50대는 분리, 그 위는 60대 이상으로 묶임 |
| ④ 일감 수요 | 업종 × 시간 구간 × 요일별 결제 피크 | 카드 데이터1 + [워크넷 채용정보 API](https://www.data.go.kr/data/3038225/openapi.do)로 검증 | API 활용신청 필요 |
| ⑤ 연결 인프라 접근성 | 관계형 업종 점포와 5060 전용 기관까지의 거리·밀도 | [상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do), [중장년내일센터](https://www.work24.go.kr/wk/u/a/1000/seniorCenterInfo.do), [서울시 50플러스센터](https://news.seoul.go.kr/welfare/50plus), [경로당 표준데이터](https://www.data.go.kr/data/15114136/standard.do) | **상가정보 확보 완료.** 강남 66,269개·춘천 17,984개 점포, 좌표 결측 없음. 센터 좌표는 미확보 |

②가 이 안의 핵심입니다. 추정 신호를 실측 통계로 대체하면서, 동시에 우리 분석 단위(행정동 × 성 × 연령)와 정확히 맞아떨어집니다.

## 4. 모델링과 검증

- **대리 라벨**: 행정동별 5060 남성 1인세대 비율. 제공 데이터에서 만든 지표 ①③④⑤로 이 라벨을 예측하는 모델을 만들고, 일부 동을 남겨 성능을 평가합니다.
- **관측 수**: 행정동 47개 × 6개월 = 282개. 격자 단위(약 1,600개) 피처를 보조로 사용합니다. 표본이 작으므로 교차검증과 신뢰구간을 함께 제시합니다.
- **대조군 설계**: 30·40대를 대조군으로 두어 "5060에만 나타나는 패턴"인지 확인합니다.
- **이상탐지 병행**: 라벨 없이도 또래 활동과 소비 패턴이 평균에서 벗어난 동을 검출해 대리 라벨 방식과 교차 확인합니다.
- **외부 검증**: 지역사회건강조사 우울감 경험률(시군구), 고독사 실태조사(시도)와 방향이 일치하는지 대조합니다. 단위가 커서 보조 근거로만 씁니다.

## 5. AI 에이전트 설계

**사용자**: 동 주민센터 복지 담당자, 중장년내일센터·50플러스센터 담당자.

**운영 흐름** (과제 요구 흐름과 동일)

1. **위험 신호 탐지** — 월별로 동 × 성 × 연령 지표를 갱신해 임계값을 넘은 집단을 추출
2. **위험 수준 판단** — 위험 지수를 5단계로 구분
3. **원인 분석** — 모델 기여도(SHAP)를 LLM이 자연어로 해석. "이 동은 1인세대 밀도보다 관계형 인프라 부재가 주된 원인"
4. **자원 추천** — [복지서비스 API](https://www.data.go.kr/data/15090532/openapi.do), 워크넷 구인 공고, 인근 중장년 기관을 결합해 제시
5. **우선 지원 도출** — 위험도 × 자원 접근성으로 우선순위를 매기고 담당자용 보고서 생성

**역할 분담**: 위험도 계산과 원인 분해는 재현 가능한 모델이 담당하고, LLM은 해석·추천·문서 생성만 맡습니다. 대회 규칙상 참가자가 분석 결과를 직접 검증하고 설명할 수 있어야 하기 때문입니다. 담당자 승인 단계를 흐름에 포함합니다.

## 6. 작업 순서

1. ~~**외부 데이터 확보**~~ — 완료. 행안부 1인세대와 상가정보를 내려받아 `data/external/`에 보관하고 대상 지역 수록을 확인했습니다(`docs/external_data.md`, `scripts/build_external.py`).
2. **행정동 매핑 (최우선 과제)** — 데이터마다 행정동 코드 체계가 다릅니다. SK 유동인구는 `11230510`(구 행정자치부 체계), 행안부 1인세대는 `1168051000`, 상가정보는 `11680640`(행정표준코드)를 씁니다. **코드로 직접 조인할 수 없으므로**, SK 격자의 UTM-K 좌표를 행정동 경계 shp에 공간 조인해 표준 행정동을 붙이는 방식으로 해결합니다. 이 작업이 끝나야 지표 ②③⑤를 결합할 수 있습니다.
3. **지표 산출 파이프라인** — ①③④⑤를 동 단위 피처 테이블로 생성
4. **모델링과 검증** — 대리 라벨 예측 + 이상탐지, 성능 평가
5. **에이전트 구현** — 도구 정의, 복지자원·구인정보 연결, 시나리오 3건
6. **보고서·발표 자료** — LLM 활용 설명자료, 재현 코드 정리

## 7. 한계와 대응

| 한계 | 대응 |
|---|---|
| 집계 데이터라 개인을 특정할 수 없음 | 결과를 동·성·연령 단위로만 산출. 대상자 접촉은 기관의 기존 경로로 |
| SK에 연령 × 시간 교차가 없음 | 시간 기반 5060 추정을 지표에서 제외하고 1인세대 실측으로 대체 |
| 6개월이라 추세 분석이 어려움 | 시계열 변화 대신 연령대 간·지역 간 수준 비교로 논지 구성 |
| 결제 피크가 곧 채용 수요는 아님 | 대리 지표임을 명시하고 워크넷 구인 공고로 검증 |
| 강남은 외지 결제가 많음 | 데이터2의 고객 거주 시도로 주민 결제만 필터링(본 문서 수치에 이미 적용) |
| 특정 동을 위험 지역으로 지목하면 낙인 효과 | 개인 식별이 아닌 자원 배분 도구로 포지셔닝하고, 보고서에 윤리 검토 항목을 포함 |

## 8. 결정이 필요한 사항

- [ ] 타겟 연령 범위 확정 (50~69세인지, 카드 데이터의 50대·60대 구간을 그대로 쓸지)
- [ ] 남성 한정 여부 (고독사 통계는 남성 집중이나, 여성 대조 분석을 넣을지)
- [ ] 관계형(사회적) 소비 업종 분류 확정 — 현재 `scripts/explore_signals.py`의 25개 업종은 임의 분류이며, 채택 시 핵심 산출물이 되므로 근거가 필요합니다
- [ ] 1차 서류 마감일 확인 후 작업 순서에 일정 배정
