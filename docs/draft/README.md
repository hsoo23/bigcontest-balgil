# 초안 뼈대

**배포 윤지 · 2026-10-09** (원래 10/11 예정, 당겨 둡니다)

> 이 폴더는 **보고서 원고**입니다 — `scripts/build_report.py`가 `01_문제.md` ~ `10_한계.md`를 입력으로 읽어 `reports/발길_분석보고서.md`를 조립합니다. 파일 머리줄의 담당·기한 표시와 「남은 일」 메모는 **작업용이고 빌드가 걷어냅니다** — 제출물에는 들어가지 않습니다.

각자 자기 절 파일을 열어 **채우기만** 하면 됩니다. 제목과 소제목은 이미 맞춰 놨으므로 바꾸지 마세요 — 바꾸면 통합 편집에서 다시 맞춰야 합니다.

## 쓰는 법

1. 파일을 열면 **`〈 〉`로 묶인 자리**가 채울 곳입니다
2. 숫자는 **최종 수치표에서만** 가져옵니다. 수치표에 없으면 `〈수치표: 체류비중 춘천 남 50대〉`처럼 **이름만 적어 두고** PR 본문에 값과 재현 경로를 적어 주세요 — 윤지가 수치표에 먼저 올린 뒤 치환합니다
   - **2026-10-18 기준 보고서 열한 절의 `〈수치표: …〉` 자리는 0개입니다.** 발표자료도 23개 모두 치환됐습니다
   - 치환 뒤에는 `python scripts/check_numbers.py`로 **수치표에 없는 숫자가 0개**인지 확인합니다
3. 서식·용어·문체는 [`보고서_목차.md`](../보고서_목차.md) 3절. **왼쪽 말만 씁니다**
4. [`실행계획.md`](../실행계획.md) 1-2절 "쓰면 안 되는 문장"은 **자기 절에서 직접** 지킵니다
5. 그림·표는 파일로 따로 주고 본문에는 `[그림 3: 설명]`만 적습니다
6. **제출본은 `python scripts/build_report.py`로 묶습니다** — 열 절에 부록 A·B·C(수치표 · 외부 데이터 목록 · 불일치 처리)를 붙여 `reports/발길_분석보고서.md`를 만듭니다. 머리줄의 「담당 · 기한」, 끝의 「남은 일」·「채우기 전 확인」, 깃허브 링크는 **묶을 때 걷어냅니다**(이슈 번호는 남습니다). 그래서 이 파일들에 작업 메모를 그대로 두어도 됩니다 — 제출 직전에 지우지 마세요
