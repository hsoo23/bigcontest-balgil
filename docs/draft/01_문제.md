# 1. 문제 — 고립은 발길이 좁아지고 끊기는 일이다

**담당 윤지 · 10/20까지 · 초안 2026-10-09**

## 1.1 기존 체계가 보는 것과 못 보는 것

주제 설명자료의 배경은 *"기존의 사후 대응 중심 복지 체계만으로는 위기 징후를 조기에 발견하고 대응하는 데 한계"*입니다. 한계는 두 군데에서 생깁니다.

**첫째, 늦습니다.** 기존 탐색은 격월입니다. 끊김은 하루 사이에 생기는데 다음 탐색일까지 평균 〈수치표: 조기성 지연일〉일을 기다립니다.

**둘째, 경제 지표로만 봅니다.** 소득·수급 여부로 거르면, 돈은 있지만 발길이 끊긴 사람은 명단에 오르지 않습니다. 우리가 올린 신호 중 경제 지표로는 상위가 아니었던 집단·동의 비율이 〈수치표: 기존 체계 보완율〉입니다.

## 1.2 고립을 무엇으로 볼 것인가

고립은 마음의 상태라 직접 재지 못합니다. 그러나 **고립된 사람은 밖으로 덜 나갑니다.** 가는 곳이 줄고, 가더라도 사람을 마주치지 않는 곳으로 가고, 늘 가던 리듬이 끊깁니다.

> **고립은 발길이 좁아지고 끊기는 일입니다.**

이 정의가 가진 성질이 이 기획의 전부입니다. **발길을 재면 확인해 줄 사람이 같이 나옵니다.** 발길이 어디로 향했는지를 알면 그 자리에 있는 사람이 누구인지도 알기 때문입니다. 위험도만 내는 지표에는 없는 성질입니다.

## 1.3 그래서 네 면으로 잽니다

| 면 | 묻는 것 |
|---|---|
| 양 | 몇 곳에 가는가 |
| 질 | 얼굴을 아는 곳인가 |
| 연속성 | 늘 가던 대로 가는가 |
| 터전 | 닿을 곳이 있는가 |

네 면은 바뀌는 속도가 다릅니다. 끊김은 하루, 좁아짐은 달 단위입니다. 에이전트의 주기가 둘로 갈리는 이유가 여기서 나옵니다(7절).
