# 1. 문제 — 고립은 발길이 좁아지고 끊기는 일이다

**담당 윤지 · 10/20까지 · 초안 2026-10-09**

## 1.1 기존 체계가 보는 것과 못 보는 것

주제 설명자료의 배경은 *"기존의 사후 대응 중심 복지 체계만으로는 위기 징후를 조기에 발견하고 대응하는 데 한계"*입니다. 한계는 두 군데에서 생깁니다.

**첫째, 늦습니다.** 기존 탐색은 격월입니다. 끊김은 하루 사이에 생기는데 다음 탐색일까지 평균 〈수치표: 조기성 지연일〉일을 기다립니다.

**둘째, 경제 지표로만 봅니다.** 소득·수급 여부로 거르면, 돈은 있지만 발길이 끊긴 사람은 명단에 오르지 않습니다.

> **이 둘째 한계를 숫자로 재지 못했습니다.** 올린 신호 중 경제 지표로는 상위가 아니었던 집단·동의 비율(「기존 체계 보완율」)을 세려면 **동 단위로 공개된 경제 지표**가 있어야 하는데, 분석 기간에 맞는 자료를 구하지 못했습니다(9.1-1, 10.5). **문제 제기는 정성으로 두고, 못 낸 사실을 한계에 적습니다.**

## 1.2 고립을 무엇으로 볼 것인가

고립은 마음의 상태라 직접 재지 못합니다. 그러나 **고립된 사람은 밖으로 덜 나갑니다.** 가는 곳이 줄고, 가더라도 사람을 마주치지 않는 곳으로 가고, 늘 가던 리듬이 끊깁니다.

> **고립은 발길이 좁아지고 끊기는 일입니다.**

이 정의가 가진 성질이 이 기획의 전부입니다. **발길을 재면 확인해 줄 사람이 같이 나옵니다.** 발길이 어디로 향했는지를 알면 그 자리에 있는 사람이 누구인지도 알기 때문입니다. 위험도만 내는 지표에는 없는 성질입니다.

## 1.3 그래서 네 면으로 잽니다

| 면 | 묻는 것 |
|---|---|
| 양 | 몇 곳에 가는가 |
| 질 | 얼굴을 아는 곳인가 |
| 연속성 | 늘 가던 대로 가는가 |
| 터전 | 닿을 곳이 있는가 |

네 면은 바뀌는 속도가 다릅니다. 끊김은 하루, 좁아짐은 달 단위입니다. 에이전트의 주기가 둘로 갈리는 이유가 여기서 나옵니다(7절).

## 1.4 두 안은 같은 대상의 다른 면이었습니다

1차 회의에서 두 기획이 나왔습니다. 「안심 신호등」은 발길의 **양**을 공정하게 재는 방법을 찾았고, 「단골 안부」는 발길의 **연속성**과 **상대방**을 발견했습니다. 다른 기획이 아니라 **같은 대상의 다른 면**이었습니다.

그래서 이 보고서는 두 안을 나란히 놓고 고르지 않습니다. **발길에서 다시 연역합니다.** 양·질·연속성·터전 네 면이 두 안을 모두 품고, 그 위에서 탐지·판단·원인·연결이 한 개념으로 이어집니다.

## 1.5 버린 것

| 버린 것 | 왜 |
|---|---|
| **당사자 앱** | 아무도 자기 고립을 진단받으려고 앱을 깔지 않습니다. 발길은 이미 데이터에 남아 있어 물어보지 않아도 잽니다 |
| **AI가 기관에 직접 전화** | 실현성과 윤리 질문을 부릅니다. 신청서 초안까지가 에이전트의 몫입니다 |
| **행정동 376칸 테이블** | 카드의 공간 단위가 시군구 2개뿐이라 강남 22개 동의 카드 지표가 전부 같은 값이었습니다. **허위 해상도**입니다 |
| **90대 집단** | 발길이 무엇인지 알 수 없을 만큼 부정기합니다 (하루 37건, 변동계수 0.46) |

버린 이유가 모두 같습니다. **데이터가 받쳐주지 않거나, 사람이 해야 할 일을 기계에 넘기는 것**입니다.
