# 3. 데이터와 전처리 — 해상도가 다르다

**담당 수경(제공 데이터)·현수(외부 데이터) · 10/20까지**

> 규정의 「데이터 분석 근거 자료」 앞부분입니다. 외부 데이터는 **출처·수집 방법 명시와 원본 파일 제출이 규정 필수**입니다([`제출요건.md`](../제출요건.md) 3절).

## 3.1 제공 데이터 (수경)
〈카드: 기간·단위·공간 단위·항목〉
〈SK: 기간·단위·공간 단위·항목〉
〈비식별·집계 형태라는 점과 그것이 분석에 지우는 제약〉

## 3.2 외부 공공데이터 (현수)
〈7종 표 — 이름·제공기관·기준시점·공간단위·라이선스〉
> `docs/external_data.md`가 `register_external.py`로 자동 생성됩니다. **손으로 옮겨 쓰지 말고 그 출력을 붙입니다.**

## 3.3 행정동 연결 (현수)
〈47개 동 코드 기준, SGIS 대조 결과, 좌표→행정동 방법〉

## 3.4 해상도 한계 — 하지 않는 것 (수경)
〈카드는 시군구까지라서 동 단위 끊김을 말하지 않는다〉
〈SK는 연령×시간 교차가 없다〉
〈행안부 시점 — 받은 자료가 2025년 7~12월이라 분석 기간과 맞는다. 기존 2026-08 자료를 쓰지 않은 이유〉
