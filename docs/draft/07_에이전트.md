# 7. 에이전트 설계 — 주기·도구·판단 (E4)

**담당 수경 · 10/21까지**

> 규정의 최소 요구 성과물 네 번째 — *위험 탐지·판단 로직, 복지자원 추천 체계, 대응 프로세스 및 활용 시나리오*. 그리고 「문제 구성」의 **재현 가능 설명**(판단 기준·위험도 산출 방식·추천 연계 과정을 구체적으로)이 여기서 충족돼야 합니다.

## 7.1 두 갈래 주기
〈끊김 루프 주 1회 / 좁아짐 루프 월 1회 / 알림 즉시. 7일 창을 쓴 통계적 이유〉

## 7.2 도구 11개
〈표 — 도구 이름·하는 일·어떤 면·데이터. 이름이 네 면과 대응한다는 점〉

## 7.3 위험 탐지·판단 로직
〈탐지 → 판정 → 보정 → 명부 교차 → 권고의 각 단계 입출력〉

## 7.4 복지자원 추천 체계
〈복지로 499건·1365 216건을 상태별로 어떻게 고르는가〉

## 7.5 대응 프로세스
〈0~2단계와 종결. 실행은 사람이 한다는 경계〉
