### 규정의 「최소 요구 성과물」 네 가지를 어디서 덮는가

주제설명자료 PDF가 요구하는 넷입니다. **하나라도 비면 1차에서 걸립니다.**

| 규정 요구 | 발표자료 | 보고서 |
|---|---|---|
| 핵심 인사이트 및 비즈니스 제안 | 1·2·13·14장 | 1·9절 |
| 데이터 분석 근거 자료 (EDA, 지역·연령계층별 비교, 위험 지표·분석 방법 상세) | 3~6장 | 3·4절 |
| 예측·분류 모델링 결과 (개발 과정·성능 평가·위험도 해석, **재현 가능한 코드**) | 7·8장 | 5절 + 저장소 |
| AI 에이전트 설계 결과 (탐지·판단 로직, 추천 체계, 대응 프로세스, 활용 시나리오) | 9~12장 | 7·8절 |

> **LLM은 점수를 주지 않습니다**(규정: "LLM 활용 여부는 평가에 반영하지 않음"). 10장에서 모델과 LLM의 분담을 말할 때는 **개인정보가 LLM에 실리지 않는다는 설계**로 말하고, LLM을 성과로 말하지 않습니다.

### 다섯 마디 (10/10 승인 안)

1. 고립은 발길이 좁아지고 끊기는 일이다.
2. 발길은 양·질·연속성·터전, 네 면으로 잰다.
3. 명절·날씨 같은 이유는 먼저 지우고, 지워지지 않는 끊김만 신호로 올린다.
4. 신호가 오르면 본인이 등록한 단골부터 사람이 확인한다.
5. 발길이 돌아왔는지로 끝을 판단한다.

그리고 한 줄로 줄이면: **발길을 재면 확인해 줄 사람이 같이 나온다.**

> 이 다섯 줄은 `실행계획.md` 13절과 같습니다. **고칠 거면 10/10에 고치고, 그 뒤에는 모든 문서가 이 문장을 글자 그대로 씁니다.** 슬라이드 제목·보고서 절 제목·README가 서로 다른 말을 쓰면 전달력에서 깎입니다.

## 3. 공통 서식 (10/11 배포분)

셋이 따로 써도 한 사람이 쓴 것처럼 보이게 하는 최소 규칙입니다.

### 용어 — 왼쪽만 씁니다

| 쓴다 | 안 쓴다 |

| 발길 / 발길의 양·질·연속성·터전 | 외출 지수, 이동량, 활동성 |
| 좁아짐 · 끊김 · 터전 없음 | 위험군, 고위험, 은둔형 |
| 체류 / 식사 / 익명 / 병원·약국 | 대면, 관계형, 필수 소비 |
| 집단 (시군구×성×연령 36칸) | 세그먼트, 코호트 |
| 동 (행정동 47칸) | 지역, 권역 |
