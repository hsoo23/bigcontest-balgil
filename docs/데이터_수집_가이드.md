# 데이터 수집 가이드 (계정 작업이 필요한 항목)

로그인·활용신청이 필요해 자동으로 받을 수 없는 데이터 목록입니다. 받으신 뒤 아래 "저장 방법"대로 두시면 정제 스크립트를 붙이겠습니다. 파일을 직접 주셔도 됩니다.

우선순위는 **A(에이전트 필수) → B(지표 검증) → C(선택)** 순입니다.

## 저장 방법 (공통)

```bash
python scripts/register_external.py --init <슬러그>   # data/external/<슬러그>/meta.json 생성
# 내려받은 원본 파일을 data/external/<슬러그>/ 에 가공 없이 그대로 둡니다
# meta.json의 name·provider·url·collected_at·reference_date·spatial_unit·license를 채웁니다
python scripts/register_external.py                   # docs/external_data.md 목록 자동 갱신
```

원본을 그대로 두는 이유는 대회 규정상 **활용한 원본 파일 제출이 필수**이기 때문입니다. 파일 크기와 SHA-256 해시가 자동 기록되어 제출본과 분석본이 같다는 것을 보일 수 있습니다.

API 키는 파일이 아니라 `.env`에 저장하고 절대 커밋하지 않습니다(`.gitignore`에 이미 포함).

```
WELFARE_API_KEY=...      # 복지로(중앙부처·지자체 공통)
WORKNET_API_KEY=...      # 워크넷 채용정보
VOLUNTEER_API_KEY=...    # 1365 봉사참여정보
```

## A. 활용신청이 필요한 API (에이전트 필수)

공공데이터포털 로그인 → 데이터셋 페이지 → **활용신청** → 대부분 자동 승인되어 즉시 인증키가 발급됩니다. 신청서의 활용 목적란에는 아래 문구를 쓰시면 됩니다.

> 2026 빅콘테스트 AI데이터 활용 분야 참가작으로, 사회적 고립 위험 지역·인구집단을 분석하고 복지자원을 추천하는 AI 에이전트를 개발하는 데 활용합니다. 비영리 공모전 목적이며 결과물은 분석 보고서와 코드로 제출합니다.

| 슬러그 | 데이터셋 | 왜 필요한가 |
|---|---|---|
| `welfare_central` | [한국사회보장정보원 중앙부처복지서비스](https://www.data.go.kr/data/15090532/openapi.do) | 에이전트가 추천할 복지서비스 목록. 지원대상·선정기준·신청방법 제공 |
| `welfare_local` | [한국사회보장정보원 지자체복지서비스](https://www.data.go.kr/data/15108347/openapi.do) | 강남구·춘천시 자체 복지서비스 |
| `volunteer_1365` | [행정안전부 봉사참여정보서비스_GW](https://www.data.go.kr/data/15157582/openapi.do) | **역할 상실에 역할로 답하는 자원.** 지역별 봉사 일감. REST, 자동승인 |
| `worknet_jobs` | [한국고용정보원 워크넷 채용정보](https://www.data.go.kr/data/3038225/openapi.do) | 일감 수요 지표의 외부 검증 + 5060 적합 구인 추천. **LINK형이라 포털에서 활용신청이 불가하며, 페이지의 `바로가기`로 이동한 제공기관 사이트에서 별도 발급받아야 합니다. 우선순위는 가장 낮습니다** |

복지로 2종과 1365는 API 유형이 REST이고 개발·운영단계 모두 자동승인이라, 신청하면 바로 키가 나옵니다. 워크넷만 LINK형이라 절차가 다릅니다.

인증키만 `.env`에 넣어 주시면 수집 스크립트는 제가 작성합니다. 키 발급 화면의 **일반 인증키(Encoding)** 값을 쓰시면 됩니다.

## B. 수동 조회가 필요한 통계 (지표 검증)

### B-1. 고용보험 자격상실자 — 평일화 지수 검증용 (가장 중요)

- 슬러그: `ei_separation`
- 사이트: [고용행정통계 월별 피보험자현황](https://eis.work24.go.kr/eisps/rpt/reptDtl.do?menuId=020020020)
- 조회 조건
  - 분석항목: **(사업장)시도, (사업장)시군구, 연령_10세, 성별, 상실사유**
  - 측정값: **상실자수(월)**
  - 기간: **2025년 7월 ~ 2025년 12월**
  - 지역: 서울 강남구, 강원 춘천시 (전국을 받아 두시면 전국 비교에도 씁니다)
- 내려받기: 화면의 엑셀 내려받기
- 왜 필요한가: 우리가 만든 평일화 지수(카드 결제의 평일 편중)가 **실제 퇴직과 같은 방향으로 움직이는지** 검증하는 유일한 수단입니다. 이게 있으면 "우리 지표가 은퇴를 잡는다"를 증명할 수 있고, 없으면 추정에 머뭅니다.

### B-2. 2025년 각 월의 1인세대수·인구 — 라벨 시점 정합성

- 슬러그: `mois_monthly_2025`
- 사이트: [행정안전부 주민등록 인구통계](https://jumin.mois.go.kr/)
- 받을 것: **2025년 7월 ~ 12월** 각 월의 (1) 행정동별 세대원수별 세대수, (2) 행정동별 성별·연령별 인구수
  - 메뉴: 주민등록 인구 및 세대현황 → 행정구역(읍면동)별, 연령별/세대원수별 선택 → 조회 후 CSV
  - 지역은 서울 강남구, 강원 춘천시만으로 충분합니다
- 왜 필요한가: 지금 확보한 1인세대 데이터는 **2026년 8월 한 시점**이라 분석 기간(2025년 7~12월)과 어긋납니다. 대리 라벨로 쓰려면 같은 기간 값이 필요합니다.

### B-3. 시군구 단위 검증 지표

- 슬러그: `kosis_validation`
- [지역사회건강조사 우울감 경험률](https://kosis.kr/statHtml/statHtml.do?orgId=177&tblId=DT_H_MENTAL_DEPRESS) — 시군구별, 최근 연도
- [사망원인통계 자살률](https://kosis.kr/visual/nsportalStats/detailContents.do?statJipyoId=3669&listId=D&vStatJipyoId=4840) — 시군구 × 성 × 연령(5세), 최근 연도
- KOSIS는 조회 시 로그인 리다이렉트가 걸려 자동 수집이 불가합니다. 화면에서 조건을 지정하고 CSV로 내려받아 주세요.
- 왜 필요한가: 우리 위험 지수가 높은 지역이 실제 우울감·자살률이 높은 지역과 방향이 맞는지 보는 외부 검증입니다. 시군구 단위라 보조 근거로만 씁니다.
