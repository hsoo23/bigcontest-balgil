### [#14](https://github.com/hsoo23/bigcontest-balgil/issues/14)이 윤지에게 물은 두 가지 — 답했습니다

- [x] **B1을 빼고 재분석 모델만 쓰는 것에 동의** — 동의합니다. 다만 "B1을 뺀다"가 아니라 **대상이 바뀐 것**입니다. 통합본(구 분류) 모델 ①~④ 재실행만 불가이고, B1 과제 자체는 수경의 `reanalysis/b3_models.py`로 **돌려서 PR #16에 올렸습니다(리뷰 중)** — `reanalysis/reference/` 전수 대조 **17/17 일치**. 보고서 본문에는 좁아짐 분류와 발길 예상만 씁니다
- [x] **D3 「발길 상세」의 SHAP을 재분석 모델로 낼 수 있는지** — **낼 수 있습니다.** **좁아짐 분류 모델**이 `RandomForestClassifier`라 `shap.TreeExplainer`로 정확히 계산됩니다(`shap==0.48.0`은 이미 `requirements.txt`에 고정). `weekly_panel.csv` 800행 × 변수 11개로 돌려 가산성 검증을 통과했고, 한 칸의 상위 5개 기여 합이 모델 확률과 일치했습니다. **단, 모델 입력 11개에 터전 변수(체류형 점포·경로당)가 없습니다** — `b4_ground`는 동 단위 별도 산출이라 모델이 쓰지 않습니다. 화면의 SHAP 막대는 **집단 단위의 양·질·연속성·추세만** 설명하므로, 터전 칸은 SHAP 대상에서 빼고 막대에 단위를 적어야 합니다. 기여도 1위는 3주 이동평균이었습니다(추세로 잡힘). 양성 중 **새로 들어온 칸이 31건**뿐이라 수치 옆에 표본 수를 같이 적습니다
