# D3 화면 4개 — 와이어프레임 초안

**작성 현수 · 2026-10-09** · 회의 ① 손그림의 바탕. 수치는 재분석 결과이고 10/17 수치 동결 뒤 교체합니다.

화면에 나오는 개인·동 이름 사례는 모두 **가상**입니다(협업규칙 6절). 카드 지표는 시군구까지만 보이고 동에는 붙이지 않습니다(실행계획 2절 절대 원칙).

## ① 주간 브리핑 — "이번 주 누구를 확인할까"

```
┌──────────────────────────────────────────────────────────────┐
│ 발길 주간 브리핑   2025-W40 (9/29~10/5)      [강남|춘천|전체] │
├──────────────┬──────────────┬──────────────┬─────────────────┤
│ 확인 권고 집단│ 지난주 대비   │ 신호 분포      │ 끊김 종류         │
│     3        │   ▼ 2        │ 🔴1 🟠1 🟡1 🟢9 │ 대면1 장보기1 병원1│
├──────────────┴──────────────┴──────────────┴─────────────────┤
│ 확인 권고 목록 (60대+ 12칸 중, 아래 신호 배치는 예시)            │
│  신호  집단              7일 묶음 변화   끊김 종류   다음 행동   │
│  🔴   춘천 여성 80대      ▼ 48%         장보기형    본인 전화 → │
│  🟠   춘천 여성 70대      ▼ 36%         대면형     단골 가게 → │
│  🟡   춘천 남성 80대      ▼ 31%         병원약국형  기관 확인 → │
├──────────────────────────────────────────────────────────────┤
│ 이번 주 보정으로 지운 신호: 명절 n건 · 날씨 n건 · 30·40대 공통 n건│
└──────────────────────────────────────────────────────────────┘
```

- 행을 누르면 ② 발길 상세로 갑니다.
- 아래 줄 "지운 신호"는 ④ 보정 전·후로 이어지는 입구입니다.

## ② 발길 상세 — "왜 이 집단인가" (우선순위 1)

```
┌──────────────────────────────────────────────────────────────┐
│ ← 춘천 여성 80대    🔴 빨강 · 장보기형        나이 보정 순위 n위 │
├────────────────────────────┬─────────────────────────────────┤
│ 양  몇 곳에 닿는가          │ 질  얼굴을 아는 곳인가            │
│ [26주 선그래프, 같은 성 50대 │ [체류 비중 막대: 50대 7.1% → 80대  │
│  점선 비교]                 │  3.7%]  병원·약국 비중 ↑          │
├────────────────────────────┼─────────────────────────────────┤
│ 연속성  늘 가던 대로 가는가  │ 터전  닿을 곳이 있는가 (동 단위)   │
│ [7일 묶음 막대 + 평소 흔들림 │ [춘천 25개 동 미니 지도]           │
│  3배 띠, 하락 주 강조]       │ 체류형 점포·경로당 하위 동 3곳      │
├────────────────────────────┴─────────────────────────────────┤
│ 근거 문장 (고정 문장 틀)                                       │
│ "추석 뒤 7일 묶음 필수 소비가 평소 흔들림의 3배 넘게 줄었습니다. │
│  계절·30·40대 공통 변화·병원약국을 보정한 뒤에도 남은 감소입니다."│
├──────────────────────────────────────────────────────────────┤
│ 변수 기여도 (SHAP) 상위 5개 가로 막대                           │
└──────────────────────────────────────────────────────────────┘
```

- 양·질·연속성은 집단(시군구) 단위, 터전만 동 단위입니다. 두 칸 사이에 단위가 다르다는 표시를 둡니다.
- 쓰면 안 되는 문장(실행계획 1-2절)이 근거 문장에 들어가지 않게 틀을 고정합니다.

## ③ 지도 — "어느 동에 닿을 곳이 없나"

```
┌──────────────────────────────────────────────────────────────┐
│ 터전 지도   [강남 22동 | 춘천 25동]   레이어: ☑터전 지수 ☑체류형 점포│
│                                              ☑경로당 ☐도서관 ☐복지│
├───────────────────────────────────────┬──────────────────────┤
│                                       │ 선택한 동: 개포1동      │
│        [행정동 단계구분도]              │ 60세+ 천 명당 체류형 1.4 │
│        + 점포·경로당 점 중첩            │ 경로당 n · 도서관 n      │
│                                       │ 60대+ 유동 비중 n%      │
│                                       │ 같은 구 안 순위 22/22    │
├───────────────────────────────────────┴──────────────────────┤
│ 격차: 60세+ 천 명당 체류형 점포 20~200배 (개포1동 1.4 ↔ 역삼1동 286.2)│
└──────────────────────────────────────────────────────────────┘
```

- 카드 지표는 이 화면에 올리지 않습니다(허위 해상도).
- 강남과 춘천은 한 지도에 섞지 않고 탭으로 나눕니다(목적지 효과로 직접 비교 금지).

## ④ 보정 전·후 — "헛알림을 얼마나 지웠나" (우선순위 1)

```
┌──────────────────────────────────────────────────────────────┐
│ 보정 전·후    [보정 끄기 ○──● 켜기]     추석 주간 강조           │
├──────────────────────────────────────────────────────────────┤
│ 주 × 집단 히트맵 (26주 × 12칸)                                 │
│   보정 끔: 추석 주간 열이 전부 빨강                              │
│   보정 켬: 춘천 고령 몇 칸만 남음                                │
├──────────────────────────────┬───────────────────────────────┤
│ 명절 주간 헛알림               │ 병원·약국 분리 시               │
│ 보정 전 105 → 보정 후 26 (−75%)│ 81 → 8 (−90%)                  │
├──────────────────────────────┴───────────────────────────────┤
│ 단계별: ① 계절 n건 → ② 30·40대 차감 n건 → ③ 병원·약국 분리 n건    │
└──────────────────────────────────────────────────────────────┘
```

- 위 두 칸은 실행계획 12절의 "사용 가능" 수치입니다. 단계별 n건은 B3 재실행(윤지) 결과로 10/17 이후 채웁니다.
- 토글 하나로 "보정을 끄면 경보로 덮인다"는 주장이 한눈에 보여야 합니다.
