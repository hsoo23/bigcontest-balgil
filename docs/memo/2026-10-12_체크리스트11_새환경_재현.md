## 찾은 것

**1. README 윈도우 활성화 명령이 깨져 있었습니다 — 이 PR에서 고침**

`.venv\Scripts\activate`의 `\a`가 제어 문자(BEL)로 바뀌어 `.venv\Scripts` + BEL + `ctivate`로 저장돼 있었습니다. #22에서 제가 넣은 줄이고, 화면에서는 `Scriptsctivate`처럼 보입니다. 처음 받는 사람이 그대로 복사하면 실패합니다.

**2. `data/reference/dong_code.csv`를 다시 만들면 `MOIS_CD`가 채워집니다 — 현수 확인 필요**

`build_dong_code.py`를 돌리면 47행 모두 `MOIS_CD`(행안부 10자리 코드, 예: 신북읍 `5111025000`)가 들어갑니다. 저장소 파일은 이 열이 비어 있습니다(윤지가 #2에서 짚은 것과 같습니다). 다른 열은 그대로입니다. 행안부 정제본이 들어오기 전에 만든 파일이라 생긴 차이로 보이고, 재현이 깨진 것은 아닙니다. 현수가 다시 만들어 커밋하면 저장소와 실행 결과가 같아집니다. 이 PR에서는 현수 파일이라 건드리지 않았습니다.

**3. numpy·scipy는 고정되어 있지 않습니다 — 지금은 문제없음**

두 환경에서 pip이 다른 버전을 골랐지만 기준 결과는 같았습니다. 10/22 최종 재현에서 차이가 나면 그때 `requirements.txt`에 고정을 더하는 것을 회의에 올립니다(혼자 올리지 않는 규칙).
