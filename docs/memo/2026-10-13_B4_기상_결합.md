# B4 기상 결합 — 날씨는 예상 모델이 아니라 끊김 알림의 설명 꼬리표로 씁니다

**현수 · 2026-10-13** · 재현: `python scripts/explore_weather.py` (선행 `build_weather.py`, 3절은 `reanalysis/a0_load_clean.py`)

## 1. 결합 테이블

`data/reference/weather_daily.csv`는 일자 × 도시 368행입니다(git에 올림). 원본 없이도 모델·보정·화면이 같은 기상값을 씁니다.

- 열: 평균·최저·최고기온, 강수량, 신적설, 궂은 날 표시 4종
- 출처: ASOS 서울(108)·춘천(101), 2025-07-01~12-31

궂은 날 기준은 기상청 특보 기준을 일자료로 옮긴 **근사값**입니다. 특보 발령 이력은 아닙니다.

| 표시 | 기준 | 강남 | 춘천 |
|---|---|---|---|
| 폭염 | 최고기온 ≥ 33℃ | 25일 | 30일 |
| 한파 | 최저기온 ≤ −12℃ | 0 | 3 |
| 큰비 | 일강수량 ≥ 30mm | 15 | 18 |
| 대설 | 신적설 ≥ 5cm | 1 | 판정 불가(미관측) |
| 하나라도 | | 41 | 51 |

## 2. 끊김 알림은 큰비 주간에 몰립니다 — 공통 충격 보정 뒤에도

`break_daily`(재분석 b2)의 `date`는 **7일 창의 끝날**입니다. 그래서 그날 하루가 아니라 창 안 7일의 궂은 날 수를 봤습니다.

| 단계 | 알림(집단×창) | 창 안 큰비(평균) |
|---|---|---|
| 모든 창 | — | **0.65일** |
| 보정 없음 | 131 | 1.17일 |
| 계절형 보정 뒤 | 150 | 1.31일 |
| 공통 충격 보정 뒤 | 44 | **1.45일** |

**보정을 더할수록 큰비 비중이 오히려 커집니다.** 공통 충격 보정은 같은 도시 30·40대의 편차를 빼는 방식입니다. 비가 오면 30·40대보다 어르신의 발길이 더 줄어서, 빼고 남은 몫이 "어르신만의 끊김"으로 남습니다. 최종 끊김(주황·빨강) 44건 중 **32건은 창 안에 큰비가 있었습니다.**

가장 큰 덩어리는 **추석 직후 춘천 동시 빨강**입니다.

| 창 끝날 | 춘천 끊김 집단 | 창 안 큰비 |
|---|---|---|
| 10/09 | 4 | 0 |
| 10/10 | 4 | 1 |
| 10/11 | 5 | 2 |
| 10/12 | 6 | 2 |
| 10/13 | 5 | 3 |
| 10/14 | 3 | 3 |

- 춘천 강수량: 10/10 34.5mm, 10/11 33.3mm, 10/13 31.4mm
- 이 창들에는 연휴(10/3~10/9) 끝자락도 함께 걸립니다
- 10/09 창은 비가 없는데도 4집단이 끊겼습니다. 그래서 비만으로 설명되지는 않습니다

큰비가 없는 최종 끊김은 12건입니다.
- 강남 11/14~16, 12/25~26(성탄)
- 춘천 10/08~09
- 춘천 남 70대 8/01: 창 7일이 전부 폭염

## 3. 발길 예상에 기상을 넣어도 나아지지 않습니다

b3 ② 발길 예상과 같은 입력·분할(11/15~12/31 시험)·모델에 기상 열(평균기온·강수량·큰비)만 더했습니다.

| | 기준선 | 부스팅 | 부스팅 + 기상 |
|---|---|---|---|
| 중앙값 MAPE | 6.9 | 7.1 | 6.9 |
| 나아진 집단 | | | 6/12 |

- 춘천 80대는 오히려 크게 나빠집니다: 여 21.7 → 33.5, 남 16.0 → 19.5
- 표본이 하루 수십 건이라 기상 열에 과적합한 것으로 봅니다
- 시험 기간(11~12월)에는 큰비가 거의 없어 기상 열이 일할 날도 적습니다

→ **예상 모델에는 기상을 넣지 않습니다.** 분석결과 8절의 "기온 있으면 품질 향상"은 확인되지 않았습니다.

## 4. 제안 — 날씨는 지우지 말고 꼬리표로 답니다

| 어디 | 무엇 | 담당 |
|---|---|---|
| 끊김 알림 (D1 `agent.py`) | 창 안에 큰비·폭염·한파가 있으면 **「날씨 가능」 꼬리표**. 알림은 지우지 않습니다. 기준이 근사값이고, 비 오는 주에 실제로 고립이 깊어질 수도 있기 때문입니다 | 수경 (`weather_daily.csv` 읽기) |
| 동시 끊김 규칙 (10/17 안건) | "같은 도시 고령 6집단 중 3개 이상이 같은 창에서 끊기면 공통 사건부터 확인"에서 공통 사건 후보로 **연휴·큰비**를 같이 보여 줍니다 | 수경·현수 |
| 시연 기준일 (10/17 안건) | 10/14 춘천 동시 빨강을 쓰면 **"큰비 사흘 + 연휴 끝"이라는 설명이 같이 떠야** 합니다. 그러지 않으면 심사에서 "비 와서 안 나간 것 아니냐"를 그대로 받습니다. 10/01 강남 남 60대 주황은 창 안 큰비가 1일입니다 | 전원 |
| 화면 ① "날씨 n건" (D3) | 꼬리표 수를 셉니다 | 현수 |
| 보정 3단계 서술 (B3, E3) | "공통 충격 보정 뒤에도 큰비 주간이 남는다"를 한계 또는 4단계 후보로 적습니다 | 윤지 |
