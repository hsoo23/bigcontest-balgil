# 발길 — 추진 계획

팀원 「안심 신호등 × 단골 안부 통합 최종본」을 흡수해 다섯 트랙으로 나눈 실행 계획입니다. 분업을 정하기 위한 문서입니다.

> **문서 세 개가 한 세트입니다.** 「발길 — 기획안」은 무엇을 만드는가, 「발길 — 분석 결과」는 그 근거, 「발길 — 추진 계획」은 누가 언제 무엇을 하는가입니다. 여기에 「발길 — 제출 요건」(마감과 규정), 「발길 — 제출물 목차와 서식」(무엇을 어떻게 쓰는가), 「발길 — 설계자료 2종 요구 항목」(규정상 함께 내는 것)이 붙습니다.

## 0. 한 장 요약

**한 문장**

> 고립은 발길이 좁아지고 끊기는 일이다. 발길을 재면(양·질·연속성·터전) 확인해 줄 사람이 같이 나온다.

**담당**

| 이름 | 역할 | 맡는 트랙 |
|---|---|---|
| **수경** | 지표·에이전트 | A 전체, **B2·B5**, D1, 조기성 계산 |
| **현수** | 터전·화면 | C 전체, D2·D3·D4, **B4** |
| **윤지** | 모델·통합 | **B1·B3**, E 전체(통합·편집) |

> **트랙 코드(A~E)는 작업 묶음이고 사람 배정과 1:1이 아닙니다.** B 트랙이 둘로 갈립니다 — 지표 검증 성격인 **B2·B5는 수경**, 모델 재실행인 **B1·B3은 윤지**, 전처리 성격인 **B4는 현수**입니다. 5절 트랙 코드표에 담당이 이름으로 적혀 있습니다.
>
> 이 배정은 10/10 회의에서 확정합니다. 1차 안 대비 두 가지를 옮겼습니다 — **B4(기상 통일)를 윤지 → 현수**, **조기성 계산을 윤지 → 수경**. 윤지가 10/14~16에 모델 재실행·보정·기상·조기성·수치표를 한꺼번에 맡으면 과부하이고, E1 통합 편집에 쓸 시간이 없습니다(11절).

## 1. 지금 어디까지 왔는가

| | 통합 최종본 (팀) | 발길 1차 기획안 | 재분석 (`balgil/b0~b5`) |
|---|---|---|---|
| 강점 | **문서·그림만 남음** — 모델·`agent.py` 코드 부재 ([#14](https://github.com/hsoo23/bigcontest-balgil/issues/14)) | 개념이 하나로 묶임, 동 코드 검증 | **새 분류로 안정성·보정·좁아짐 분류·발길 예상 실행 완료** |
| 지표 | 5개 | 양·질·연속성·터전 | 체류 비중 확정 |
| 모델 | 4개 실행 (구 분류) | 설계 | 새 분류 모델 2개 결과 있음 |
| 남은 것 | **없음 — 코드가 없어 재실행 불가** | 구현 | 팀 분류표 대조 |

**결론**: 새로 만들 것은 거의 없습니다. **재분석 코드를 팀 분류표에 맞춰 돌리고, 결과를 문서와 화면으로 옮기는 일**이 남았습니다.

### 1-1. 보고서에 써도 되는 것 (확인됨)

> **모든 수치는 제과점을 어느 분류에도 넣지 않은 기준입니다.** 제과점을 체류 또는 식사에 넣으면 값이 달라지므로, A5 민감도에서 두 경우를 확인한 뒤 결과가 같음을 보고서에 한 줄로 적습니다. 그 전에는 이 표의 값을 다른 기준과 섞어 쓰지 않습니다.

| 주장 | 수치 |
|---|---|
| 나이 들수록 체류 비중이 낮다 | 춘천 남성 50대 7.2% → 80대 2.7%, 여성 7.1% → 3.7% / 12집단 모두 6개월 내내 50대보다 낮음 |
| 한 업종에 기대지 않는다 | 체류 업종 11개를 하나씩 빼는 44가지 모두 유지 (최약 0.80) |
| 줄어든 자리는 병원·약국 | 춘천 남성 8.7%(50대) → 26.4%(80대) |
| 양과 질은 다른 것을 잰다 | 상관 **0.35** (정의 차이는 아래 주석) |
| 보정하면 헛알림이 준다 | 명절 주간 **105 → 26건(−75%)**, 병원·약국 분리 시 **81 → 8건(−90%)** |
| 보정 후 끊김은 춘천에 몰린다 | 추석 후 필수 소비 춘천 여성 80대 −48%, 여성 70대 −36%, 남성 80대 −31% / 강남 −15~−18% |
| 좁아짐 예측이 기준선보다 낫다 | AUC 0.887 → **0.973**, 새 진입 **18/31** (기준선 0/31). AUC 차이 95% 구간 0.041~0.160 |
| 동 순위는 안정적 | 월별 순위 상관 최솟값 강남 0.99 / 춘천 0.85 |

> **양·질 상관 두 값**: 재분석 기준 **0.35**, `scripts/explore_quality.py` 기준 **0.404**(14셀, 유효 발길 수 ↔ 체류 비중)입니다. 셀 수와 지표 정의가 달라 생긴 차이이고 둘 다 "부분적으로 독립"이라는 같은 결론을 냅니다. **본문은 0.35를 쓰고**, 분석 근거 자료(E2)에 두 값과 정의 차이를 함께 적습니다. 레포 코드 출력과 보고서가 어긋나지 않게 하기 위함입니다.

### 1-2. 보고서에 쓰면 안 되는 것

| 쓰면 안 되는 문장 | 이유 | 대신 쓸 문장 |
|---|---|---|
| "대면이 먼저 끊기고 필수가 따라 끊긴다" | 필수가 먼저, 더 크게 내려감 | "끊김은 세 종류로 나타난다" |
| "필수만 돌아오고 체류는 안 돌아오는 미해소를 잡는다" | 집단 데이터에서 0건 | "개인 단위(본인 등록 후)에서 쓰는 규칙으로 설계했다" |
| "추석 뒤 필수는 바로 회복한다" | 병원약국 제외 시 장보기 7~19일 뒤 회복 | "회복 시점은 업종별로 다르며 원인은 단정하지 않는다" |
| "모델이 새 위험을 예측한다" | 최대 변수가 최근 3주 평균(흔들림 평활화) | "한 주 먼저 잡았다. 새 진입 31건의 소표본이다" |
| "교동 여성 70대가 5일 연속…" | 카드는 시군구까지만 | "춘천 여성 70대 … (가상 데이터)" |
| "편의점으로 대치된다" | 편의점도 18.0% → 7.9% 감소 | "병원·약국이 채운다" |

## 2. 발길 — 개념 틀

### 네 면

| 면 | 묻는 것 | 지표 | 재는 단위 | 순위 산정 단위 |
|---|---|---|---|---|
| **양** | 몇 곳에 닿는가 | 유효 발길 수, 업종×시간×요일 칸 수 | 도시×성별×연령 **36칸** | 60대+ **12칸** |
| **질** | 얼굴을 아는 곳인가 | **체류 비중**, 취미 업종 | **36칸** | 60대+ **12칸** |
| **연속성** | 늘 가던 대로 가는가 | 상대 침묵, 단골 달력, 저녁 결제 비중 | 60대+ 12칸 × 7일 묶음 | 동일 |
| **터전** | 닿을 곳이 있는가 | 60대+ 유동 비중, 저녁 유동, 체류형 점포, 경로당·복지시설 | **47개 동** | 동일 |

**지표는 36칸으로 재고, 순위는 60대+ 12칸에서만 냅니다.** 36칸 전체에 나이 보정을 걸면 10·20대가 상위로 올라오기 때문입니다(변경 #5). 지표 36칸에서 **90대를 뺀 32칸**이 **좁아짐 분류 모델의 학습 표본**(32칸 × 26주, `b3_models.py`)이고, 보고서의 "가장 위축된 집단" 서술은 12칸 안에서만 합니다.

**절대 원칙**: 카드 지표는 동에 붙이지 않는다 (카드=시군구, 통신·상가=동).

### 업종 분류 — 확정안 (10/10 승인 예정)

> 2절 분류표는 **확정안**입니다. 10/10 회의에서 팀 기존 분류표와 대조해 승인하면 확정됩니다(5절 A1). 승인 전에는 이 표 기준으로 작업을 진행하되, 결과를 되돌릴 수 있게 커밋을 분리합니다.

| 구분 | 업종 |
|---|---|
| **체류** | 커피전문점, 미용실, 미용서비스, 싸우나/목욕탕, 안마/마사지, 노래방, 유흥업소, 스포츠시설, 헬스장, 실내/실외골프장, 학원/학습지 |
| **식사** | 한식, 중식, 일식, 양식, 기타요식 |
| **익명** | 편의점, 할인점/슈퍼마켓/양판점, 기타식품, 농수산물, 정육점, 주류판매, 패스트푸드 |
| **병원·약국** | 약국, 일반병원, 종합병원, 한의원, 치과병원, 기타의료, 보건소 |
| 제외 | **제과점** — 재분석 기준을 그대로 지켜 어느 쪽에도 넣지 않는다. A5에서 "체류에 넣으면 / 식사에 넣으면"을 민감도로 돌려 결과가 같음을 확인한 뒤 보고서에 한 줄로 쓴다 |

> `주류판매`가 기존 `features.py`에서 `SOCIAL_MCT`와 `ALONE_MCT` 양쪽에 들어가 있었습니다(A3에서 수정). 상가정보 쪽은 중분류명 `'비알코올 '`에 뒤쪽 공백이 있어 커피전문점 2,950개가 패턴에서 빠졌습니다(C2에서 수정).

### 두 잣대 (결정 완료)

| 잣대 | 순위 | 용도 |
|---|---|---|
| 수준(원값) | 춘천 남성 80대 → 춘천 남성 70대 → 춘천 여성 80대 → 춘천 여성 70대 | **주 서사**: 지금 가장 얇은 곳 |
| 나이 보정 (60대+ 12칸, 26주) | 강남 여성 60대(26주 내내 3위 안) → 강남 여성 70대 → 춘천 여성 60대 | **조기 발견**: 아직 젊은데 벌써 좁은 집단 |

> 수준 잣대의 상위 4칸이 모두 춘천인 것은 "춘천이 강남보다 고립됐다"는 뜻으로 쓰지 않습니다 (1-2절, 강남 목적지 효과). 보고서에는 **"춘천 안에서 가장 얇은 집단"**으로 씁니다.

## 3. 시스템 설계

```
[진단]  양·질 (카드, 36칸)  ×  터전 (통신·상가·시설, 47개 동)
           ↓                          ↓
      만성 취약도 V                동네 우선순위
           ↓
[감시]  연속성: 7일 묶음이 평소 흔들림의 3배 넘게 하락
           ↓
[보정]  ① 계절(앞뒤 4주 같은 요일) → ② 같은 도시 30·40대 차감 → ③ 병원·약국 분리
           ↓
[판정]  V × S → 5단계 신호등 (끊김 종류 표시)
           ↓
[대응]  노랑: 집단·동 단위 확인 질문, 자원 카드
        주황·빨강: 본인 전화 → 본인이 등록한 단골 가게 → 방문 → 기관
           ↓
[종결]  집단: 7일 묶음 평균 복귀 (업종별 기준일)
        개인(본인 등록자): 횟수 복귀 + 체류 복귀 2층 판정
           ↓
[학습]  결과를 임계값·자원 매칭에 되먹임
```

### 본인 등록 (개인 연결의 유일한 경로)

| | 역할 |
|---|---|
| 카드 데이터 | 그 집단 발길이 어느 **업종**에 쏠렸는지 → 무엇을 물을지 설계 |
| 본인 등록 (최초 1회) | "자주 가시는 곳 두세 군데가 어디세요?" / "연락이 안 될 때 그 가게에 안부를 여쭤봐도 될까요?" → 실제 가게, 동의 확보 |
| 단골 달력 | 그 업종이 언제 닫는지 → 언제 먼저 전화할지 |

> 카드 데이터는 개별 가맹점을 식별할 수 없습니다(주제설명자료 7쪽). 그래서 데이터가 알려주는 것은 **업종**까지이고, 실제 가게는 본인 등록으로 받습니다. "상대방이 특정된다"가 아니라 "물어볼 업종과 후보 가게가 좁혀진다"가 정확한 표현입니다.

### 종결 판정 (개인 단위, 설계)

| 관측 | 판정 |
|---|---|
| 발길 횟수 + 체류 모두 복귀 | 해소 |
| 횟수만 복귀, 체류 그대로 | 미해소 (밥은 드시지만 사람은 안 만난다) |
| 변화 없음 | 단계 상향 |

> 집단 데이터로는 이 규칙을 실증하지 못했다고 보고서에 명시합니다. **설계로서 제시**합니다.

### 끊김 종류 표시

| 종류 | 기준 | 확인 방식 |
|---|---|---|
| 대면형 | 체류·식사 감소 | 단골 가게 안부 |
| 장보기형 | 익명 중 장보기 업종 감소 | 본인 전화, 방문 |
| 병원약국형 | 병원·약국 감소 | 건강 확인, 기관 연계 (회복이 7~19일 걸릴 수 있어 종결 기준일을 달리 둠) |

### 화면 4개 (D3)

| 화면 | 보여줄 것 |
|---|---|
| 주간 브리핑 | 확인 권고 집단, 지난주 대비 감소, 신호별 건수, 끊김 종류 |
| 발길 상세 | 양·질·연속성·터전 네 면 동시 표시, 근거 문장, 변수 기여도(SHAP) |
| 지도 | 동별 터전 지수 + 체류형 점포·경로당 중첩 |
| 보정 전·후 | 보정을 끄면 추석 주간이 경보로 덮이는 화면 (105 → 26건) |

> **「발길 상세」의 SHAP은 집단 단위입니다.** 재분석 모델 ①(`RandomForestClassifier`, 변수 11개)에서 `shap.TreeExplainer`로 냅니다 — 돌려서 가산성까지 확인했습니다. 그런데 **모델 입력에 터전 변수(체류형 점포·경로당)가 없습니다.** `b4_ground`의 동 단위 산출은 모델이 쓰지 않기 때문입니다. 그래서 SHAP 막대는 **양·질·연속성·추세만** 설명합니다. 단위는 **모델 패널 32칸**(도시×성별×연령, 90대 제외)이지 지표 패널 36칸이 아닙니다 — `b3_models.py`가 90대를 뺍니다. 터전 칸은 막대에 넣지 말고, 막대 제목에 「집단 단위 기여도」라고 적어 동 단위 터전 칸과 구분합니다. 기여도 1위는 3주 이동평균이었습니다.

## 13. 발표 다섯 마디

**본 제출물이 발표자료이므로 이 다섯 줄이 제출물의 목차 그대로입니다.** 슬라이드 배치는 **「발길 — 제출물 목차와 서식」** 1절.

1. 고립은 발길이 좁아지고 끊기는 일이다.
2. 발길은 양·질·연속성·터전, 네 면으로 잰다.
3. 명절·날씨 같은 이유는 먼저 지우고, 지워지지 않는 끊김만 신호로 올린다.
4. 신호가 오르면 본인이 등록한 단골부터 사람이 확인한다.
5. 발길이 돌아왔는지로 끝을 판단한다.
