# 한 도시에서 배운 분류기가 다른 도시에서도 서는가

**윤지 · 2026-10-10**

## 무엇을 알고 싶었나

강남에서만 학습한 좁아짐 분류기를 춘천에 적용해도 성능이 유지되는가. 반대 방향도.

## 왜 그걸 물었나

기획안 7절 「발길 지수 — 합성 + 타당성 검증」의 네 항목 중 **지역 일반화**. 네 항목 중 유일하게 전제가 깨지지 않은 것이었습니다(나머지 셋은 [아래](#남은-의문)).

`b3_models.py`가 이미 "칸 통째로 빼기" 교차검증을 하지만 **같은 도시의 다른 칸이 학습에 남습니다.** 도시를 통째로 빼야 "다른 동네에서도 서는가"에 답합니다.

## 조건

| | |
|---|---|
| 코드 | `scripts/explore_city_transfer.py` (이 실험으로 새로 씀) · 커밋 `de53299` |
| 데이터 | `data/processed/reanalysis/weekly_panel.csv` (832행, 32칸 × 26주) |
| 환경 | Python 3.10.10, scikit-learn 1.7.2(고정값), 시드 0 |

## 방법

라벨이 있는 800행을 도시로 갈라 한쪽에서만 학습하고 다른 쪽 전체에 적용했습니다. 변수 11개, 모델은 로지스틱(표준화 후)과 랜덤포레스트, 둘 다 `class_weight='balanced'`. 비교 기준으로 ① "이번 주 상위가 다음 주에도 상위"라는 기준선 ② 같은 도시 안에서 앞 21주로 배워 뒤 4주에 적용한 경우를 함께 냈습니다.

## 결과

| 학습 → 적용 | 모델 | AUC | 새 진입을 잡은 수 |
|---|---|---|---|
| 강남 → 춘천 | 기준선 | 0.894 | 0 / 12 |
| 강남 → 춘천 | 로지스틱 | 0.973 | 9 / 12 |
| 강남 → 춘천 | 랜덤포레스트 | 0.980 | 5 / 12 |
| 춘천 → 강남 | 기준선 | 0.878 | 0 / 19 |
| 춘천 → 강남 | 로지스틱 | 0.978 | 18 / 19 |
| 춘천 → 강남 | 랜덤포레스트 | 0.953 | 11 / 19 |
| 강남 앞 21주 → 뒤 4주 | 랜덤포레스트 | 0.970 | 1 / 4 |
| 춘천 앞 21주 → 뒤 4주 | 랜덤포레스트 | 0.969 | 1 / 3 |

## 판단

**통과. 다만 "일반화된다"고 쓰지 않고 "두 도시 사이에서는 무너지지 않았다"까지만 씁니다.**

도시를 건너도 같은 도시 안에서 배운 것(0.969~0.970)과 거의 같습니다. 운영 시에는 **임계값만 지역마다 다시 잡으면** 된다는 근거로 씁니다. 두 점으로 일반화를 주장하면 심사에서 바로 걸리므로 표현을 눌렀습니다.

## 예상과 달랐던 것

**기준선이 생각보다 높았습니다**(0.878~0.894). 좁아짐 상위 칸이 주마다 거의 그대로여서, AUC만 보면 모델의 기여가 작아 보입니다. 그래서 이 실험 뒤로 **보고서의 서술 기준을 AUC에서 "새로 들어오는 칸을 잡는가"로 바꿨습니다** — 기준선은 정의상 0건입니다.

로지스틱이 랜덤포레스트보다 새 진입을 더 잘 잡는 것도 예상 밖이었습니다(춘천→강남 18 대 11). 표본이 작아 단순한 모델이 덜 과적합한 것으로 보이는데 확인하지 않았습니다.

## 남은 의문

- 로지스틱이 새 진입에서 앞서는 이유를 확인하지 않았습니다
- 타당성 검증 나머지 셋의 상태: **대리 라벨 상관**은 전제를 이미 폐기(PR #17), **독립 지표 상관**은 `evening`이 모델 입력이라 전제가 깨져 대상을 바꿈([3자 대조](2026-10-10-표본치우침-3자대조.md)), **양·질 분리**는 수경 몫(B5)
- 도시가 둘뿐이라 세 번째 지역이 없으면 이 이상 말할 수 없습니다
