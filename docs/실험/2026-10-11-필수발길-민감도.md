# 필수 발길에 패스트푸드·주류판매를 넣을 것인가

**윤지 · 2026-10-11**

## 무엇을 알고 싶었나

「장보기형」(필수 발길)에 패스트푸드와 주류판매를 넣으면 끊김 판정이 얼마나 달라지는가.

## 왜 그걸 물었나

이슈 [#2](../../../../issues/2) 회의 질문 ②. 수경의 **D1이 끊김 종류 라벨 규칙을 이걸로 짭니다.** 안 정하면 "넣지 않는 쪽으로 짜고 상수로 빼 두겠다"로 가기로 돼 있었는데, 의견이 아니라 데이터로 가를 수 있는 질문이었습니다.

`b0_common.py`의 `ESS`에 둘이 빠져 있어 **코드는 이미 제외하고 돌아가고 있었습니다.** 문서에서 넣기로 하면 코드와 어긋납니다.

## 조건

| | |
|---|---|
| 코드 | `reanalysis/b2_continuity.py` (main `c2d37be`), `ESS`만 바꿔 두 번 실행 |
| 데이터 | `card1.pkl`·`card2.pkl` (신한카드 제공 데이터 2025-07-01~12-31, 거주자 필터) |
| 환경 | Python 3.10.10, pandas 2.3.3, scikit-learn 1.7.2(고정값), 시드 0 |

## 방법

`b0_common.ESS`를 두 가지로 두고 `b2_continuity.py` 본문을 같은 입력에 실행했습니다. 출력은 원본을 덮지 않도록 `data/processed/reanalysis_ess/`로 돌렸습니다.

- **현행**: `['할인점/슈퍼마켓/양판점','편의점','기타식품','농수산물','정육점'] + MED`
- **추가**: 위 + `['패스트푸드','주류판매']`

대상은 60대·70대·80대 12집단, 7일 창, 보정 3단계.

| 빨강(필수까지) | 40 | 41 |

| 공통 사건 주간 알림 (2) | 26 | 27 |

총량은 1건 차이지만 **사건 구성이 바뀝니다 — 4건이 생기고 3건이 사라집니다.**

| 집단 | 날짜 | |

| 강남 남 80대 | 2025-12-26 | 성탄 다음 날 |
| 강남 남 80대 | 2025-07-30 | |
| 강남 남 60대 | 2025-11-14 | |

## 판단

**넣지 않습니다. 코드 현행 유지.**

두 가지 이유입니다. ① 새로 생긴 4건 중 **2건이 연휴**입니다. 주류판매는 연휴에 크게 출렁이므로, 필수에 넣으면 보정 3단계로 걸러 내려던 잡음을 다시 들여옵니다 — 설계의 핵심("이유는 먼저 지운다")과 반대 방향입니다. ② 「필수」는 끊기면 생존이 위태로운 소비(장보기·의료)인데 패스트푸드는 대체 가능하고 주류는 필수재가 아닙니다. 넣으면 빨강의 뜻이 흐려집니다.

문서에 **"장보기형 = 익명 중 장보기 업종. 패스트푸드·주류판매는 익명이지만 필수에 넣지 않는다"**를 한 줄 적습니다.

## 예상과 달랐던 것

**총량만 보고 "차이 없음"으로 끝낼 뻔했습니다.** 14건 대 15건이라 1건 차이로 보였는데, 사건을 하나씩 맞대 보니 **4건이 생기고 3건이 사라진 것**이었습니다. 합계가 비슷하다고 같은 결과가 아닙니다.

## 남은 의문

- 사라진 3건이 어떤 성격인지 보지 않았습니다. 생긴 쪽만 확인했습니다
- 주류판매를 **빼고** 패스트푸드만 넣으면 어떻게 되는지는 안 돌렸습니다. 연휴 잡음이 주류 쪽에서 온다는 추정의 직접 증거는 없습니다
