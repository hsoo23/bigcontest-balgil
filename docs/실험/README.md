# 실험 기록

**재 보고 정한 것, 돌려 보고 버린 것, 예상과 달랐던 것**을 한 장씩 남깁니다. 코드만 남으면 "무엇을 만들었나"는 남지만 **"왜 그렇게 정했나"가 사라지고**, 나중에 같은 자리를 다시 재게 됩니다.

## 규칙 넷

1. 측정하거나 비교해서 무언가를 정했으면 `YYYY-MM-DD-<짧은이름>.md` 한 장을 남깁니다
2. [`_템플릿.md`](_템플릿.md)의 칸을 지우지 않습니다. 쓸 내용이 없으면 **"해당 없음"**이라고 적습니다
3. **실험이 끝난 그 자리에서** 적습니다. 나중에 쓰면 조건(데이터 버전·패키지 버전·시드)이 기억에 의존합니다
4. **코드 커밋을 반드시 남깁니다.** 그 사이 코드가 바뀌면 회차끼리 비교가 안 됩니다

**실패하거나 중단한 실험도 똑같이 남깁니다.** "해 봤는데 안 됐다"는 다음 사람이 같은 길로 들어서는 것을 막아 주므로 성공한 실험만큼 쓸모 있습니다.

## `docs/memo/` 와 무엇이 다른가

| | |
|---|---|
| `docs/memo/` | **무엇을 했나** — 작업 단위의 진행 기록. 협업규칙 4절 |
| `docs/실험/` | **왜 그렇게 정했나** — 측정과 판단. 조건을 적어 재현이 되게 |

같은 작업이 양쪽에 걸리면 메모에서 실험 문서를 가리킵니다. **숫자를 두 곳에 베껴 두지 않습니다** — 단일 출처는 [`최종수치표.md`](../최종수치표.md)입니다.
